## Короткі дзвінки

- A — ID клієнта (текст, зберігати початкові нулі).
- B — дата дзвінка.
- C — менеджер VIP.
- D — TL.
- E — статус від TL, змінювати лише за окремим завданням.
- F — встановлення контакту: 0; 2,5; 5.
- G — робота зі «зливом»: 0; 2,5; 5; 7,5; 10.
- H — робота з негативом/запереченнями P.R.E.P: 0; 2,5; 5; 7,5; 10.
- I — завершення: 0; 2,5; 5.
- J — формула підсумку, максимум 30. Не перезаписувати числом.
- K — перевіряючий. Для автоматичної оцінки: «АІ» (точно це значення).
- L — коментар з поясненням критеріїв та таймкодами, якщо відомі.
- M — дата перевірки.

Запис нового дзвінка розділяти на A{r}:I{r} і K{r}:M{r}. Для оцінювання наявного дзвінка записувати F{r}:I{r} і K{r}:M{r}. Ідентифікаційні поля змінювати лише якщо це потрібно за завданням. Не включати J в прямокутник із порожнім значенням: порожнє значення може стерти формулу.

## Френдлі дзвінки

- O — ID клієнта.
- P — дата дзвінка.
- Q — менеджер VIP.
- R — TL.
- S — статус від TL, змінювати лише за окремим завданням.
- T — встановлення контакту: 0; 2,5; 5.
- U — розвиток френдлі: 0; 2,5; 5; 7,5.
- V — індивідуальний підхід: 0; 2,5; 5; 7,5.
- W — заклик до гри: 0; 2,5; 5; 10. Значення 7,5 відсутнє в поточній валідації.
- X — пропозиція бонусів: 0; 2,5; 5.
- Y — робота з негативом/запереченнями P.R.E.P: 0; 2,5; 5; 7,5; 10.
- Z — завершення: 0; 2,5; 5.
- AA — невимушеність: 0; 2,5; 5; 7,5.
- AB — формула підсумку, максимум 57,5. Не перезаписувати числом.
- AC — перевіряючий, для автоматичної оцінки «АІ».
- AD — коментар.
- AE — дата перевірки.

Запис нового дзвінка: O{r}:AA{r} і AC{r}:AE{r}. Оцінювання наявного: T{r}:AA{r} і AC{r}:AE{r}. Не включати AB в прямокутник з порожнім значенням.

## Порядок внесення

1. Прочитати метадані, точну назву аркуша, заголовки, цільові клітинки та їх dataValidation. Не використовувати застарілу схему A:U / W:AU.
2. Знайти наявний запис за проєктом, типом дзвінка, ID клієнта, датою та менеджером. ID клієнта не є унікальним ID дзвінка: клієнт може мати кілька дзвінків. При неоднозначності не перезаписувати випадковий рядок.
3. Для нового запису шукати вільний рядок окремо у потрібному блоці: A для коротких або O для френдлі. Перевірити, що немає дати, менеджера, критеріїв чи коментаря попереднього дзвінка. Формули J/AB та заздалегідь заповнений перевіряючий «АІ» у K/AC не означають зайнятий рядок. Дані іншого блоку в тому самому рядку допустимі.
4. Не застосовувати append «після останнього зайнятого рядка всього аркуша»: J та AB містять заздалегідь заповнені формули. Не вставляти цілий рядок лише для одного дзвінка.
5. Менеджера і TL звіряти з 'Менеджери VIP'!A3:D997: A проєкт (betking/777/vegas), B TL, C менеджер, D логін. Імена мають точно відповідати dropdown цільової клітинки. Не транслітерувати і не міняти латинську I на кириличну І самостійно.
6. Бали передавати як числа: у JSON numberValue: 2.5, а не текст «2.5». Для інтерфейсу uk_UA — 2,5. Дати передавати як дати; у Sheets API — серійне число з наявним форматом дати або USER_ENTERED з коректною локалізованою датою. ID передавати stringValue, а не числом.
7. E/S дозволяють тільки «В роботі» та «Закрито». Це статус TL; автоматична оцінка не означає автоматично «Закрито».
8. Записувати тільки потрібні клітинки. Для updateCells використовувати fields: "userEnteredValue", не "*". Зберігати форматування, валідацію та формули.
9. Не вигадувати оцінки для відсутніх критеріїв і не замінювати відсутність оцінки нулем. Поточна SUM рахує часткову суму; числове J/AB саме по собі не підтверджує повноту оцінки.
10. Після запису перечитати цільові клітинки: ID, дату, менеджера, всі критерії, перевіряючого, коментар, дату перевірки та формулу/результат J або AB. Лише після звірки повідомляти «записано».
11. До виходу за поточну місткість перечитати метадані й розширити сітку, формули та валідації. Не вважати зазначену останню строку довічною межею.

## Формули та захисти

13.11.2026 знято 6 блокувань J/AB на Betking, 777 та Vegas. На цих трьох аркушах після перевірки protectedRanges відсутні. Формули збережені; у Vegas відновлено J103:J1000 (898 клітинок).

Для рядка r формули: J = SUM(F:I) у тому самому рядку; AB = SUM(T:AA) у тому самому рядку. Наприклад J103 = SUM(F103:I103). Якщо формула відсутня в новому рядку, відновити її окремим точним записом перед завершенням роботи.

Захисти «Гайди», «Менеджери VIP», «Зведення» збережені: ці аркуші не є ціллю запису оцінок. Зведення оновлюється від джерел автоматично.

Відсутність protectedRanges не надає доступу до файлу.
